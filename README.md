# 地籍任務靜態版 v1（候驗版）

這是適用 GitHub Pages 的網站，不需 Python、資料庫、登入或 GitHub 寫入憑證。原本後端版本仍另外保留，本包不會啟動後端。

## 首次部署

1. 解開網站 ZIP。把 `index.html`、三個 `worker-*.html`、三個 `vendor-*.html`、JS、CSS、`vendor` 與 `data` 等檔案上傳到 GitHub 專案根目錄。不要再多包一層資料夾。
2. 在 GitHub 專案 Settings → Pages，選擇 Deploy from a branch、正確分支與 `/ (root)`，等待部署完成。
3. 若專案仍是 Corry-Hsu/photosheet，預期網址為 `https://corry-hsu.github.io/photosheet/`，以 Pages 顯示的實際網址為準。網站由 main 分支根目錄部署；部署結果可在 GitHub Pages 與 Actions 檢查。
4. 管理頁是根網址；現場固定入口依序為 `worker-1.html`、`worker-2.html`、`worker-3.html`。

請透過 HTTPS 網站使用。直接雙擊 HTML 的 `file://` 模式無法完整運作。需要本機測試時，在網站資料夾執行 `python -m http.server 8000`，用 `http://localhost:8000` 開啟；手機連電腦的一般 HTTP IP 網址不保證能取得相機及定位權限。

## 初次建立資料

1. 在管理頁匯入工作 Excel，勾選類型、核對提醒與日期後確認。一行紀錄是一筆任務；不拆成每地號一筆。
2. 匯入地籍 ZIP（可直接選 T.zip，不需手動解壓），或同時選擇 KML 與 XML。先在電腦建立完整索引，再分派給現場手機。
3. 支援 KML 的 `SECTNO`／`PARCELNO` 欄位，以及 Placemark 名稱 `0582/1198`（段代碼／地號）。Excel 數字段碼582會正規化為0582，子號支援1198-1。單獨KML即可用代碼配對，不必另外匯入XML；地段名稱從Excel取得。也支援原有Lands XML地籍資料。
   匯入時會讀取Excel「段」對照表；舊資料有XML地籍名稱對照時，也可取得正確段碼。若來源列段碼與對照不同，保留原值，配對採對照代碼，但頁面不顯示配對成功／失敗提示。跨地段任務各自使用對應代碼，無唯一對照時不擅自套主地段代碼。
4. 不讀取外部 NetworkLink，不執行公式、HTML、DTD 或外部實體。KMZ 不在本版支援範圍。KML 使用標準 WGS84「經度,緯度」座標，禁止把投影公尺座標直接當經緯度。
5. 同一段代碼與地號在不同圖幅的範圍合併，完全相同的幾何片段去重。無效或退化邊界會列出提醒，不拿別筆地籍替代。
6. 在任務詳情核對全部地號。未配對可透過「修正地段地號」補正；修改前地號留在管理備份中。地籍範圍缺漏時仍可手動設定導航入口。
7. 選擇任務後，清單與地圖同步。點圖、拖動橘色圖釘或輸入經緯度可設定已核對入口；自動代表點只標示「地籍參考位置」。地籍點不保證車輛可達。

## 日常派工與發布

1. 三人設定可更改姓名，網址不變，包含自己最多三人。
2. 新匯入任務依鄉鎮自動分派：屏東市、九如鄉、里港鄉、高樹鄉、鹽埔鄉、長治鄉、麟洛鄉、內埔鄉、三地門鄉、霧台鄉、瑪家鄉給人員一，其餘給人員二。既有任務按「依鄉鎮自動分派」套用；人員三、已完成、舊月份與鎖定任務保留，鄉鎮缺漏維持原設定。仍可手動分派、修改日期與期限。跨鄉鎮任務以該列主要鄉鎮分派，不拆任務。
3. 成果日期預設取 Excel「通知」。期限預設取原表「完成」日期加臺灣時間 17:00，需自行核對。
4. 上月以前未派案不能新增分派；舊已派案保留原人、不可改派；解除後不能再派。此限制會在本機保存，不能藉改日期重開。它是作業規則，不是防止刻意修改資料的權限機制。
5. 點「選擇人員／廠商發布」，勾選要更新的入口，產生各自的 `worker-N.json` 或 `vendor-N.json` 下載連結，不壓縮。已完成任務排除；沒有任務仍可發布空清單清除舊派工。
6. 逐一下載並上傳所選 JSON 到 GitHub 的 `data` 目錄，取代同名檔。未選人員維持原派工；網頁不會自行推送 GitHub。
7. 等 Pages 部署完成，現場人員按「重新整理派工資料」，核對批次與時間。清單與匯入預覽只計算任務筆數，不顯示地號總數。

公開 Pages 的任務資料與地籍範圍可被其他人讀取；三個網址不構成權限隔離。不要發布不宜公開的案件或個資。原 XML 的統一編號、權利人資料不會被抽進地籍索引；發布包只放派工用到的地籍，不放完整索引、Excel、XML 或照片。

## 白板與工作單

- 管理頁可單筆／批次輸出白板及工作單；現場頁可輸出自己的白板。
- 白板為 A4 橫式，日期、地段、全部地號最大化顯示，底部兩行廠商／人員，無框線及多餘標題。列印請關閉瀏覽器頁首／頁尾。
- 工作單為 A4 直式。圍籬用「開口契約訂單通知表」，砍樹與雜草垃圾用「工作通知單」。保留整案數量，不按地號重複加計。
- 白板在原頁預覽並直接產生 PDF 與 PNG（2400×1697），不需要開啟空白分頁或透過手機列印轉檔；多筆可下載合併 PDF 或全部圖片 ZIP。Excel 輸出保留。
- 工作單維持列印／另存 PDF 與可編輯 Excel，沿用欄位重建格式，不是原 Excel 的逐像素複製；正式發文前核對契約內容。
- 工作單需要允許開啟文件視窗。白板可直接下載 PDF／圖片，手機可從檔案預覽儲存或分享。

## 現場照片

- 網頁相機按下拍攝時記錄時間；定位成功後製作浮水印並暫存。橫拍保留完整畫面與原比例，直拍沿用4:3中央範圍，取景框與成果一致，原圖另存。日期用任務指定日期，時分秒用拍攝當下臺灣時間，附 GPS 與精度。浮水印預設放在照片底部水平置中，透明背景、白字加陰影，不加黑色底板。
- 人員與廠商改用網頁相機直接記錄拍攝時間，不再提供「手機原生相機」選取入口。管理端原有相機工具保持原樣。
- 無GPS不產生假座標成果。定位或寫入失敗會保留當次畫面，讓使用者按「重試儲存」；尚未成功儲存時，重新整理或離開頁面仍可能遺失當次畫面。
- 照片只存本機 IndexedDB，不回傳。現場統一預覽、儲存或分享含日期與座標的成果照片，不再分成原圖與浮水印兩種操作。成果輸出JPEG（橫拍保留原比例，直拍4:3），長邊最多 4096px；原圖另存，保留原始尺寸。
- 人員入口提示至少兩張並顯示本機張數；廠商入口不顯示完成張數或兩張門檻，兩者皆不會自動標記任務完成。更換派工資料不改寫舊照片。
- 裝置時間、GPS、EXIF 不提供防偽保證。手機儲存不足、清除網站資料、無痕模式關閉都可能讓暫存消失，請主動下載。

## 備份與資料量

- 管理資料及地籍索引只在目前瀏覽器，不會在兩台電腦自動同步。下載「本機備份」後，可在另一台裝置還原。備份不含照片，請另外下載照片。
- 管理備份不要上傳 GitHub。還原須確認取代；壞檔不覆蓋原資料。管理資料與地籍索引在同一筆交易還原。
- 真實資料約 17.6 萬筆土地、310 萬個有效邊界點，首次匯入建議用電腦，手機只載入分配給自己的子集。
- 地籍索引每 1,000 筆分片存放，避開瀏覽器單筆大小上限；取消或儲存失敗不會留下半套索引。仍受裝置容量與瀏覽器配額限制。
- Excel 上限 12MB，解壓後 80MB／4,000 個內部檔案；地籍 ZIP 每包解壓後上限 1GB／30,000 檔案，單一 XML/KML 解壓上限 48MB。
- 不保證離線重新開啟整個網站，未加入 Service Worker。底圖需連網；底圖故障不影響本機地籍計算與既有導航連結。

## 地圖來源與限制

Leaflet + OpenStreetMap 標準底圖，保留來源標示，不批次預抓或離線快取瓦片。大量公開使用前，應依底圖政策選擇合適供應商。導航用 Google Maps 官方網址，不含 API 金鑰。

## 現場清單（2026-10-27）

現場頁優先顯示緊湊任務列，每頁最多50筆；搜尋在頂部，篩選與批次選取按需展開。點任務列會同步定位並帶往下方地圖；地圖旁的「任務內容／拍照」或任務列箭頭可開啟詳情。清單與地圖同頁顯示，地圖有「導航前往」按鈕，使用所選任務位置開啟Google Maps。注意事項、批次資訊與重新整理位於地圖後方的「注意事項與派工資訊」。

## 管理清單日期與完成註記

- 以成果指定日期為準，只顯示今年、本月1日起到年底的任務；舊月份、其他年度及缺日期資料不列入清單、統計或批次選取，但保留在本機資料與備份。此限制不會移除現場既有派工包。
- 管理者可在清單或詳情標記／取消已完成，也可批次操作，並篩選全部、未完成、已完成。完成註記及時間保存在本機管理資料，與備份一併保存。
- 已完成任務不可直接重新分派，須先取消完成。產生派工檔會排除已完成任務；三人皆無待辦時仍可產生空清單，用於移除舊派工。因為是靜態網站，完成註記不會自動改寫現場網址：須產生並發布新派工檔後才更新。

地籍配對在背景自動執行。清單、詳情與發布確認不顯示配對結果標籤、數量摘要或配對狀態篩選；地段地號、地圖、導航、完成狀態與資料匯入錯誤提示保留。

## 現場地圖的手機GPS

- 在地圖旁按「定位到我」，允許瀏覽器定位後顯示藍點；淡藍圓圈表示定位精度範圍，橘色圖釘仍為任務導航位置。
- 位置會在頁面前景持續更新；同一按鈕會改成「關閉定位」，再按一次即可停止定位。拖曳地圖或切換任務時不持續搶回視角，也不會改寫任務入口。
- 可按「關閉定位」移除手機位置並停止追蹤；頁面進入背景／離開時暫停，回到頁面且仍開啟定位時恢復。超過一分鐘沒有新定位的點會變灰並標示待更新。
- 即時地圖定位只存在記憶體，不寫入派工檔或回傳派工系統；拍照的GPS則依原照片流程保存在本機照片資料。定位需HTTPS與手機／瀏覽器權限；拒絕或逾時會提供重試說明，不拿任務點假裝手機位置。

## 廠商入口與手動新增（2026-10-29）

- 固定入口：`vendor-1.html` 雜草垃圾、`vendor-2.html` 砍樹、`vendor-3.html` 圍籬。發布分組與讀檔時均檢查類型，不能把另一標籤放進該入口；廠商分組不修改p1／p2／p3負責人。
- 廠商與人員共用任務資料，支援地籍多面範圍、導航、單鍵GPS、橫式拍照、透明陰影浮水印及白板。新增空白廠商資料檔，需在管理頁選擇廠商產生JSON並上傳GitHub的data資料夾後才有任務；不會擅自複製現有公開人員任務。
- 廠商照片只存本機、不回傳、不計入完成張數。管理員仍手動決定靜態版任務完成狀態；沒有加入後端或同步。
- 人員可輸入座標、拖動圖釘或點地圖設定本機入口；廠商只提供座標輸入，不提供點圖按鈕或拖曳圖釘。變更只存該瀏覽器，不改管理端或其他人；新發布批次以管理端入口為準。導航使用此裝置目前的入口。
- 管理頁「手動新增任務」可填類型、案號、成果指定日期、期限、負責人、多列地段地號、段代碼、工作項目、施作廠商／人員及選填入口。地號可用空格、頓號或逗號分隔；各任務以獨立manual識別碼保存，重匯Excel不會覆蓋。
- 手動任務沿用同一套KML配對、文件及發布流程。新增後預設依鄉鎮分派，也可指定人員三或暫不分派；舊月任務仍不能新增指派。日期不在今年本月起至年底者會保存但不顯示於管理清單，介面會提示。
- 網站仍是公開靜態版，固定類型是工作流程限制，不是身分驗證或資料存取權限。

- 人員與廠商移除「查看地圖」按鈕；點任務仍自動捲到下方地圖，不會自動開相機。
- 地圖區只保留「現場拍照」「導航前往」「重設位置」與GPS，移除地圖上的白板、任務詳情與點圖設定本機入口按鈕。清單仍可進入詳情，詳情內保留白板與拍照；尚未選任務時，現場拍照停用。
- 廠商不再顯示沒有作用的類型篩選；人員仍保留篩選與批次選取。
- 選擇現場拍照後進入滿版取景頁。橫拍顯示完整畫面並保留相機比例，不再強制裁成4:3；直拍依既有4:3範圍；拍完立即顯示已儲存的含浮水印照片，可「儲存照片」或「繼續拍下一張」。
- 儲存按鈕優先使用手機支援的檔案分享功能，讓使用者選擇儲存／分享；不支援時下載JPEG。照片已經包含日期、時間、GPS與陰影文字，不需再選原圖或額外製作浮水印。
- 相簿縮圖可直接放大查看。舊照片不刪除；現場頁以專用照片模組讀取既有資料。照片以位元組儲存，避免部分WebKit環境Blob寫入IndexedDB失敗；管理端原相機及儲存程式不變。

橫拍保留四邊與比例，最多只等比例縮小長邊至4096px。取景不再使用cover裁邊，也不要求相機提供固定4:3串流。

## 無框取景與鏡頭控制（2026-10-29）

人員與廠商取景移除示意白線框、標示文字及框外暗罩。橫拍仍保留完整畫面；直拍維持中央橫式4:3輸出。相機有提供縮放能力時顯示倍率滑桿；授權後有提供多個鏡頭時顯示鏡頭選單，排除可辨識的前置鏡頭。選單沿用裝置名稱，選擇時切換實際相機，繼續拍攝保留同一鏡頭。

網頁只能使用瀏覽器提供的相機能力。縮放可能是數位縮放，不能保證光學變焦；只有手機／瀏覽器開放超廣角鏡頭或對應倍率，才可取得更廣視野。不以畫面裁切假造0.5×；未提供能力時隱藏控制項並顯示說明，仍可正常拍照。鏡頭切換失敗可重新開啟最後成功的鏡頭。

## 任務照片批次操作（2026-10-30）

人員與廠商的任務詳情照片改成勾選／全選，顯示勾選張數；可打包勾選的含浮水印JPEG成ZIP，手機支援檔案分享時開啟分享面板，不支援時下載。ZIP已備妥後另提供下載／分享按鈕，處理手機要求再次點擊才允許分享的情況。更改勾選會清除舊ZIP，避免下載錯誤選取內容。JPEG以原檔位元組無損打包，不另收錄原始照片。

照片下方不再逐張顯示儲存／刪除按鈕，仍可點縮圖放大；拍攝後的單張儲存保留。批次刪除先確認張數，只刪本機當前任務與人員的勾選照片，資料庫交易中途失敗會整批取消，其他照片不受影響。
