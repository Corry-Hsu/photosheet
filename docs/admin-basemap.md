# 管理頁正射影像底圖

管理頁地圖上方提供三個選項，預設維持一般地圖，之後記住此瀏覽器的管理頁選擇：

- 一般地圖：OpenStreetMap。
- 屏東 UAV 正射：農業部農村發展及水土保持署 BigGIS 的屏東縣公開 WMTS，局部涵蓋。選擇時才讀取影像目錄與目前視野需要的一份影像，不同日期／區域可從第二個選單切換。
- 全區正射：國土測繪中心 PHOTO2，供全區影像備用。

## 影像範圍及日期

BigGIS 的屏東 UAV 服務是多個拍攝日期及區域的影像，不能視為全縣連續覆蓋或即時影像。管理頁顯示目前影像日期與地點；未覆蓋範圍保留一般地圖，視野完全沒有影像時顯示提示及「切換全區正射」。

每次移動地圖會選擇涵蓋中心的較新影像；中心沒有影像時取視野內較接近中心者。手動選擇日期／地點會移到該影像範圍，且在仍可見時保留選擇。影像按官方 BoundingBox 裁限顯示；範圍是外接矩形，內部也可能有影像空缺。

只有手動選擇影像地點會移動視野。切換底圖不更改任務、KML、導航入口、工作指派或照片。地籍與入口使用原本的覆蓋圖層，保持在影像上方。管理頁偏好用 `photosheet.admin.basemap.v1`，不影響現場頁的 `photosheet.field.basemap.v1`。

## 服務故障

影像目錄讀取失敗或本批 UAV 圖磚全部失敗時，自動切換國土測繪中心全區正射，並明確顯示已換來源；全區正射也無法載入時切回一般地圖。局部缺圖但仍有成功載入的影像時保留現有畫面並提示。自動備援不覆寫原本手動選擇的偏好；可再次選擇重試。

2026-11-11 實測：BigGIS 屏東 WMTS 目錄 HTTP 200，共 188 份影像；圖磚主機 `storage.geodac.tw` 的三個抽樣區域在本次執行環境連線逾時，回傳 503，未宣稱實際 UAV 圖磚已成功渲染。國土測繪中心屏東圖磚實測 HTTP 200，JPEG 256×256。不同使用端網路與外部服務的可用性可能不同。

## 官方介接來源

- [農村水保署服務介接專區](https://gis.ardswc.gov.tw/api-doc)：列明「屏東縣 UAV 正射影像 WMTS」為開放資料，供外部系統與一般使用者介接。
- [屏東 WMTS 目錄](https://gis.ardswc.gov.tw/api/ardswc/wmts/Ortho?CountyName=%E5%B1%8F%E6%9D%B1%E7%B8%A3)：GoogleMapsCompatible／EPSG:3857，矩陣 0–19。其 EPSG:4326 BoundingBox 以緯度、經度排列，讀取時轉成西南／東北範圍；圖磚路徑為 z/y/x。
- [國土測繪中心 WMTS 介接說明](https://maps.nlsc.gov.tw/S09SOA/pro/Wmts_ajax_main.jsp)：備用 PHOTO2。

服務來源標示保留在地圖右下方；沒有使用付費金鑰、帳密、影像下載代理或後端。

## 更新與驗收

本機 `data/admin-orthophoto.json` 只保存官方目錄的公開影像日期、範圍與 HTTPS 圖磚模板，不保存影像本體。使用目錄快照可免除官方 XML 目錄的跨來源讀取限制，圖磚仍直接連向官方目錄指定主機。

更新目錄後須重新發布網站：

```sh
python tools/update_admin_orthophoto_catalog.py
```

`python tests/admin_basemap_qa.py` 使用真實目錄與合成圖磚驗證正常載入、裁限、日期／來源、延遲載入、不修改視野及任務地籍、局部無影像、手動影像選擇、兩層備援、偏好隔離、錯誤目錄、遲到回應及手機／電腦版面。這些合成圖磚測試不代替外部影像服務實際可用性驗證。
