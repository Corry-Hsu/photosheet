# 整理發布資料

管理頁上方的「整理發布資料」提供靜態發布工作區。管理頁原本的 Excel 任務資料、照片及地籍索引不會被這裡的整理操作改寫。

## 一般操作

1. 開啟工具，從 GitHub `main/data` 讀取六個固定入口的公開 JSON。初次不預選任何入口。
2. 勾選要整理的人員／廠商。可以不匯入檔案，直接整理既有派工。
3. 要追加資料，可匯入一至多個派工 JSON；也可按「帶入管理頁所選入口任務」，直接使用已匯入 Excel／手動建立並完成分派的任務。按檔案內 `person.id` 辨識入口，`worker-2 (1).json` 也能辨識；輸出一律使用正式檔名。
4. 依鄉鎮、類型或文字搜尋，勾選全部篩選結果或個別任務，按「從所選入口移除勾選任務」。這只預備修改發布檔，可以在差異明細取消。相同任務若同時出現在人員和廠商入口，應同時選取這兩個入口。
5. 在「預覽差異」核對各入口新增／移除／修改的任務與 KML 數量。既有欄位預設保留原值；需修正地號、日期、導航等內容時，展開逐欄差異並勾選該欄。
6. 同一筆任務需要修正到其他入口時，先勾選修正欄位，再按「同步此欄到相同任務的其他入口」。只同步相同 ID、類型、案號及原成果日期且該欄原值相同的任務；其他入口有不同內容時保留，不猜測正確版本。同步會把相關入口加入發布選擇，請核對其差異。負責人欄位不可跨入口同步。
7. 按「核對線上版本並產生發布檔」。重新讀取 GitHub 的基準後，才顯示各個有變更入口的 JSON 下載連結。沒有變更的入口不產生檔案，不壓縮。
8. 下載並把同名檔案上傳到 [GitHub data](https://github.com/Corry-Hsu/photosheet/tree/main/data)，由 GitHub 建立提交並等待 Pages 部署。匯出本身不會更新網站。其他檔案不需上傳。

## 保留與合併規則

- 一筆 Excel 紀錄是一筆任務。不同類型／案號不能只因地號相同就合併。
- 優先按任務 ID 去重；ID 不同但「類型、案號、成果日期、全部地籍」一致時，辨識為既有任務並保留原 ID。缺少案號時只用 ID。
- 同檔內完全相同的重複 ID 只保留一筆；同 ID 卻有不同內容會拒絕整批匯入。同一批包含同入口的不同版本，也會拒絕。
- 新任務追加；既有任務只比較匯入檔有提供的欄位。未提供的欄位與未勾選的差異不刪除、不覆蓋。修正為空導航也必須明確勾選。
- 後續匯入不同版本會清除該入口先前的修正勾選與同步修正，必須重新核對；已選移除紀錄保留，但任務內容改變時必須重新確認。
- 三個廠商只能含對應「雜草垃圾」「砍樹」「圍籬」任務。人員入口只接受分派給該人的任務，其他入口的檔案不能錯放。
- KML 按 ID／縣市、段代碼、地號去重。移除任務或修正地號後，只清掉不再被任何保留任務引用的相關圖形；共用圖形保留，無關的既有圖形不擅自整理。沒有任務時可清空相關圖形。
- 新匯入卻未被任務引用的圖形不加入發布檔。地號缺少唯一 KML 配對會列出明細，不以別筆範圍代替、不推測入口。
- 既有批次、產生時間與其他入口設定預設保留，避免重設同批次的手機本機導航；首次空白「尚未發布」入口才帶入新包的批次。產生發布檔時另顯示實際核對時間。

## 舊草稿與線上版本改變

整理草稿自動存於這個瀏覽器的 IndexedDB，與原管理資料使用不同紀錄。可下載／匯入「整理草稿」換裝置繼續操作；本機儲存失敗會顯示提醒。

匯出前若 GitHub 資料變動或網路讀取失敗，整批停止，不產生任何下載檔。按「重新讀取線上版本」，重新核對差異後再產生。重讀會保留追加資料與整理意圖，但原值已變更的欄位修正不會自動套用，原任務內容有變的移除也會暫停。需要重新勾選確認；要取消則按差異裡的取消移除。

此工作區只做公開 HTTPS GET、瀏覽器本機儲存與下載，不包含 GitHub 寫入憑證。匯出後至實際上傳之間仍可能有人修改 GitHub；上傳前若隔了一段時間，請重新產生檔案，並核對 GitHub 的提交差異。靜態網站無法鎖住其他人的 GitHub 提交。

## 可驗證的完成條件

1. 六份現有資料做無操作規劃，輸出與原 JSON 在每個欄位、陣列順序及座標上相同。
2. 以同入口新檔追加，既有任務不重複；不同案號但地號相同的兩筆任務仍各自保留。
3. 僅勾選地號修正時，成果日期與已確認導航保持原值；新地號 KML 加入，舊圖形只有在沒有任務共用時移除。
4. 同時選擇人員二及雜草垃圾廠商、篩選「林邊鄉」並勾選移除，只影響這兩個入口命中的任務；其他入口與其他鄉鎮保留。
5. 下載的每份檔案能解析為有效發布包，檔名對應入口；無變更入口不提供下載，未選入口不匯出。
6. 匯出前線上基準有新增任務或修正時阻擋；重新讀取保留這些線上更新，失效的欄位勾選與移除必須重新確認。
7. 無效 JSON、錯誤廠商標籤、導航座標錯誤與相互衝突的重複 ID 拒絕匯入，不留下半批資料。
8. 重新整理可恢復草稿；管理頁原任務未被改動，現場人員與廠商頁沒有新增管理操作。
9. 360、390、844、1440 像素寬度沒有水平溢出，原本的歷史任務恢復／指派與發布仍通過回歸測試。
