# ADR-NNNN：具體決策名稱

- 狀態：提議／已採用／已拒絕／已取代
- 日期（Asia/Taipei）：
- 相關需求／PR／commit：
- 取代或被取代：列編號與範圍；沒有則寫無

## 背景

觸發情境與可查證問題；缺少證據明寫未確認。

## 決策／改了什麼

具體資料流、介面、儲存或業務規則。

## 為什麼

理由及依據；區分使用者指示、程式現況與推論。

## 未採用方案

可行方案及不採理由；不要杜撰未做過的效能比較。

## 影響與取捨

相容、資料遷移、角色隔離、使用者操作與回退條件。

## 驗證

命令、commit、預期與實際結果，失敗、未測及實機限制。更新HANDOFF與受影響規格；不要只引用舊evidence。
