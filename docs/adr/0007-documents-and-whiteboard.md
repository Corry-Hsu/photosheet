# ADR-0007：白板直接輸出與工作單分工

- 狀態：已採用（本次回溯整理；原始實作時間見PR）。
- 整理日：2026-11-20；核對基準：8258a42。
- 證據與範圍：[PR #2](https://github.com/Corry-Hsu/photosheet/pull/2)、[#8](https://github.com/Corry-Hsu/photosheet/pull/8)；[whiteboard.js](../../whiteboard.js)、[documents.js](../../documents.js)。

## 背景

白板需要大字、少框線；手機曾遇Excel可開但PDF／圖片空白。工作單仍需保留原案件欄位及可編輯版本。

## 決策／改了什麼

白板於原頁直接產生PDF與PNG、支援批次及Excel，日期／地段／全部地號最大化，底部廠商／人員。工作單保留A4直式列印與Excel，依圍籬／其他類型選格式。

## 為什麼

使用者明確指定白板視覺及手機可看成果；直接文件生成避開依賴空白彈窗與行動列印流程。

## 未採用／已取代的方案

不採以開新白頁當白板PDF成功、到處加表框標題、按地號拆開重計工作量；不承諾工作單逐像素複製原始Excel。

## 影響與取捨

字體／圖片要先就緒再輸出，真實手機下載與列印仍需驗收；工作單可能需要允許彈窗。
