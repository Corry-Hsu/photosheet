# ADR-0001：靜態系統與專案邊界

- 狀態：已採用（本次回溯整理；原始實作時間見PR）。
- 整理日：2026-11-20；核對基準：8258a42。
- 證據與範圍：[PR #1](https://github.com/Corry-Hsu/photosheet/pull/1)、本對話靜態化與獨立專案指示；[入口](../../index.html)、[db.js](../../db.js)。

## 背景

需要低維運的三人小組派工，同時保留既有照片排版工具；後端／照片回傳與本機照片編排已分成其他專案。

## 決策／改了什麼

photosheet 以 GitHub Pages main 根目錄、公開派工 JSON 與瀏覽器 IndexedDB 運作；不放遠端後端、帳號、OTP、認領與同步。land-dispatch-hub 及 CW015 分開開發，不能借同一份程式歷史就宣稱功能已互通。

## 為什麼

靜態發布免除遠端服務維運；本機管理資料與照片不必上傳，符合本對話後續縮減後端範圍的明確需求。

## 未採用／已取代的方案

未採用在 photosheet 內加入資料庫服務／Cloudflare Tunnel／NAS 後端，也未將 Google 協作平台當可直接替代原生程式功能的容器。這些仍可在獨立專案另評估。

## 影響與取捨

沒有伺服器身分驗證、同步或照片回報；固定網址與類型檢查只保護作業流程。公開 data 不放私人資料；本機資料需下載備份。不能把「沒有遠端DB」寫成「沒有任何儲存」。

## 驗證與後續

對應[規格完成定義](../SPECIFICATION.md#9-可驗證完成定義產品變更)，實際結果及未通過項目見[交接](../HANDOFF.md)。修改此決策時新增ADR並標示本編號被取代的確切範圍，不刪除本紀錄。
