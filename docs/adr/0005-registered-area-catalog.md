# ADR-0005：精簡 XML 面積資料與精確加總

- 狀態：已採用（本次回溯整理；原始實作時間見PR）。
- 整理日：2026-11-20；核對基準：8258a42。
- 證據與範圍：[PR #32](https://github.com/Corry-Hsu/photosheet/pull/32)、[#33](https://github.com/Corry-Hsu/photosheet/pull/33)；[操作](../land-area.md)、[land-area-core.js](../../land-area-core.js)、[轉換器](../../tools/build_land_area_catalog.py)。

## 背景

本機有大量含非必要欄位的XML；需要管理頁自動算任務全部地號的登記總面積，而非發布原始權利資料。

## 決策／改了什麼

本機轉換白名單欄位成907段／182597筆精簡地號JSON，放同站catalog＋四碼段檔，依任務按需讀取。完整配對才套用，十進位六位精度、地號去重、明細與段代號可查；改地號使舊結果失效。

## 為什麼

滿足使用者明確選擇「精簡後上GitHub，自動讀取」，減少載入並排除權利人／統編／持分。

## 未採用／已取代的方案

未採完整XML公開上傳、每次全讀所有地段、一般浮點加總、以KML幾何面積／持分面積替代登記面積、缺值當0或部分合計冒充完整。

## 影響與取捨

公開資料仍是快照，需重新轉換更新；面積不改施工數量。工作單、備份、發布含個案面積明細，不附完整XML。
