# ADR-0015：管理頁依成果月份統計案件與地號

- 狀態：已採用。
- 日期：2026-11-20（Asia/Taipei）。
- 起點：`7a1b75c0bd50e4b4292f1f618f19812cb06a2fbf`（PR #48 尚未合併；主線仍為 `2d0b13c`）。
- 關係：局部取代規格 R-06「統計以可見範圍為準」對新月統計的限制；既有清單摘要、篩選及批次操作仍以可見範圍為準。補充 ADR-0002 的月統計範圍，未取代任務粒度、日期或舊案生命週期。
- 證據：本次使用者要求本月／上月、三類案件與地號筆數；`admin-monthly-stats.js`、`index.html`、相關測試。

## 背景與決策

管理頁清單隱藏舊月，摘要只有任務／指派／完成數，不能直接回答某月各類工作量。新增管理專用統計區：預設本月，僅選本月或上個日曆月，以民國年月顯示。按有效且標準化的 `resultDate` 歸月，三類及合計分別顯示案件件數、地號筆數。

統計來源為管理者本機全部 `state.tasks`，包括已完成、未指派、鎖定、隱藏及重新開放的案件，不受搜尋、類型、人員、完成、日期篩選及分頁影響。一任務一件，案號相同不合併；地號依每案目前 `parcels` 筆數累加，同地號跨案件分別計筆，不以圖形數、工作數量或全月唯一地號數代替。匯入與編輯既有驗證負責禁止單案重複地號，本模組不改寫原資料。

所有既有管理 render 路徑同步重算，包含匯入／還原、新增／刪除、改成果日期／地號、完成與加回。臺灣月份改變時，回到頁面立即更新；頁面保持前景則每分鐘檢查一次。跨月保留相對選項（本月或上月），重載預設本月；切換不加回、不解鎖、不修改任務或發布資料。

## 理由與未採方案

按成果日期沿用產品日期語意，包含完成案才能顯示全月案件量。未採以期限／拍攝日分月、只計清單可見或當頁案件、改統計月便重新開放舊案、全月跨案去重地號或累計三個人員／三個廠商公開 JSON（同案可能重複出現在多入口）。只要求本月／上月，未擴充任意歷史月份或跨裝置即時同步。

## 影響與限制

增加管理專用 JS/CSS 及 HTML 區塊；共用 `app.js` 僅掛接可選管理模組，現場入口不載入。無新增儲存欄位、網路請求或資料遷移；公開 data、照片、指派與發布契約不變。只有本機已匯入的資料可統計；無日期、無效日期不計，沒有資料顯示零，不代表其他裝置或管理備份沒有案件。零資料仍顯示三類及合計。

## 驗證

單元測試驗證臺灣月界、跨年、閏日、同案號不同任務、地號跨案累加、完成／鎖定／加回及排除錯誤日期。合成 Chromium 驗證使用者範例72件／153筆、月切換、篩選獨立、實際新增／改地號／改成果日／刪除、寫入失敗回復、重載、零值、跨年及320–1440px版面與現場隔離。管理完成／空發布與前月加回必要回歸通過；實際命令及限制見[交接](../HANDOFF.md)及[本次紀錄](../verification/2026-11-20-monthly-stats.json)。未把歷史失敗或未跑全套寫成全綠。
