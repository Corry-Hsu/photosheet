# ADR-0020：文件任務交換與差異合併

2026-11-23，採用。補充0002、0004、0011；新增文件來源，不改原Excel匯入、手動新增或發布工作區規則。

## 背景

使用者以本機地籍文件產生器作為未來文件主工具，要求其新增／編修案件能送回photosheet派工。原管理備份還原會整份取代state及geo，不適合追加或核對文件欄位。

## 決策

新增專用JSON `cw015-dispatch-tasks / schemaVersion:1`，白名單傳送案件與相關KML。接收端保留原task.id，新案追加不指派，既有案逐欄明確勾選才更新。完成、指派、舊案鎖與導航不可由交換檔覆蓋；舊案改成果日仍保留原鎖。

預覽保存本頁state／features及IndexedDB state／geo快照。確認時在同一state＋geo交易重新比對，任何變更則取消；兩store原子提交，photos不寫入。新範圍只追加，同地籍既有不同範圍不覆蓋。公開發布仍走既有流程。

## 未採方案及影響

不把文件ZIP當備份、不讓文件端決定人員／完成、不按地號合併不同案、不直接輸出或上傳六入口發布包，也不引入遠端DB、GitHub寫入憑證或照片同步。

接收端只在管理index載入，現場相機與worker／vendor HTML不變。格式拒絕未知輸入欄位，但既有派工資料的未知欄位保留。完整文件特有資料仍留CW015；items保留六項及徑級，不宣稱舊photosheet工作單版型等價。原地籍與導航仍須核對。

## 實測

新增核心與真瀏覽器合成測試通過，涵蓋重匯、選欄、保留任務／設定／照片／指派／完成／導航、舊案日期改動仍鎖定、其他視窗寫入競態、儲存中止回滾及發布相容性。未跑全套相機、WebKit或實機，詳見HANDOFF及操作文件。
