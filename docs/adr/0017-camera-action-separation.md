# ADR-0017：鏡頭／倍率與快門分區

- 狀態：已採用。
- 核對基準：`354a90cceb14c007cf83c33d6b4b110cff80f3ca`（最新main，含PR #51與#52）。
- 關係：局部取代 ADR-0009 控制列的緊鄰排列；保留固定倍率、原控制尺寸、滿寬原比例影像、橫式單列與連拍生命週期。
- 來源：本次使用者以手機截圖指出鏡頭／倍率太接近拍照，容易誤按。

## 決策與理由

人員／廠商相機以分隔線與操作空間區分鏡頭設定及拍照動作。直式在快門列上方增加分隔，橫式（寬度至少600px）改在快門左側分隔，維持單列。驗收要求兩區至少24 CSS px間隔；合成瀏覽器實測直式25px、橫式45px。倍率與鏡頭控制至少44px高、快門至少54px高，不縮小觸控目標來換空間。

拍後設定區隱藏時，分隔線與新增空間一併移除，儲存／重試仍可直接操作。六個現場入口更新CSS資源版本，避免沿用舊控制間距。

## 未採方案

未採收合鏡頭選單、縮小倍率／快門、恢復滑桿、增加常駐教學、改取像比例或切換鏡頭邏輯。只新增隔離誤觸所需的空間；沒有將管理緊湊CSS套入現場相機。

## 影響與限制

僅變更 `field-camera.css`、六個現場HTML的CSS版本及相關驗證／文件。相機JS、任務、公開data、IDB照片與GPS規則不變。直式控制列略增高，仍使用既有原比例滿寬及可捲動取景；不宣稱所有影像一次可看完，也不能以合成點擊推定真人誤觸率已降低。

## 實際驗證

`full_width_camera_qa.py`新增人員／廠商各390×844、320×568、600×320、844×390量測，確認間隔、控制尺寸、分隔區點擊不拍照、快門可達、原尺寸取景、拍後分隔移除與串流沿用。`camera_optics_qa.py`及`field_photo_flow_qa.py`必要回歸通過；本次三組皆通過，無新增失敗。不是歷史全套或實機全綠；P0原生多頁GPS問題仍待確認。見[交接](../HANDOFF.md)及[驗證紀錄](../verification/camera-action-separation.json)。
