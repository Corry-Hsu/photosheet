# ADR-0016：管理頁緊湊版面與常駐說明移除

- 狀態：已採用。
- 日期：2026-11-20（Asia/Taipei）；起點：`2dc059396345f311f51ba2941af66dc13a30ce40`（PR #49）。
- 關係：局部取代 ADR-0015 月統計的獨立直排呈現及初版常駐說明，統計口徑與更新邏輯不變。沿用 ADR-0012 管理／現場版面分離；未取代現場相機控制及影像尺寸決策。
- 來源：本次使用者要求善用畫面空間、減少留白，能移除的說明文字移除。

## 決策與理由

新增只由管理頁載入的 `admin-compact.css`。桌面1100px以上將管理工具與月統計並排，較窄視窗直排；980px以下工具列四欄，整理發布／發布派工各跨兩欄。合併類型、人員、完成及可展開日期篩選列（日期展開時獨佔整列），縮短頁首、面板、表格、任務列與對話框間距；桌面一般控制最小36px，手機最小44px高。清單／地圖原有980px切換門檻保留。

移除首頁品牌副標、重複操作與廠商JSON教學、月統計長說明及地圖靜態教學；長按鈕標題縮短。成果月份、件／筆單位、清單日期範圍／隱藏筆數、任務資料、10個管理功能及廠商入口保留。月統計完整定義留在規格與ADR，不常駐佔畫面。發布公開風險與「產檔未更新網站」仍在發布對話框；刪除確認、進度／錯誤、影像來源／日期／備援訊息及地圖動態狀態保留。

## 未採方案

未用全站CSS縮小現場相機／GPS按鈕、隱藏所有 `.muted` 或 `p`、刪除功能、縮小全部字體或裁切長地號來求緊湊。也未把地圖改成貼邊現場版、不移除來源標示、不改任務與派工資料。這是管理頁版面調整；沒有全站或實機全面驗收證據。

## 影響與驗證

管理HTML、專用CSS與共用app.js中的管理清單範圍短文案變更；現場頁不載入緊湊CSS，相機／照片／資料契約不變。以同一組12件合成任務、960px視窗高度比較，第一筆任務的頁面位置：1440px由1100.19降至392px；390px由1562.78降至810px；320px由1961.38降至842px。不是實機顯示保證。

`admin_compact_qa.py`驗證320／390／844／1440px無橫向溢出、手機44px控制、10個管理按鈕、篩選／廠商入口／新增／發布及刪除取消、管理地圖操作；月統計、管理完成／空發布、手動刪除、底圖切換／故障備援必要回歸均通過。前一輪320px位置1018px未達目標，進一步調整工具與篩選後通過；補查展開日期時發現窄螢幕溢出，改成展開區獨佔整列與欄位自適寬度後，四種寬度重測通過；未降低資料保護斷言。命令及結果見[交接](../HANDOFF.md)與[版面驗證](../verification/2026-11-20-compact-admin.json)。

## 限制與下一步

窄手機仍需捲動，長地號會換行；高密度不代表所有功能能在一屏看完。未跑全套18組、實機、WebKit或外部圖資真實可用性，既有原生多頁GPS問題仍未解。先依序合併前置PR與本版，再核對Pages來源與實機版面。
