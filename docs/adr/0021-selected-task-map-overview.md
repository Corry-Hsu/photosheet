# ADR-0021：管理頁多選任務地籍總覽

- 狀態：已採用。
- 核對基準：`11b1c236395e52d55bdb43a21c1d91382d8caaaf`（main，保留文件任務交換與後續資料更新）。
- 關係：補充 ADR-0004、0006、0012；取代管理頁多選時仍只繪製聚焦單案的呈現。單案導航、地籍配對與現場頁決策沿用。
- 來源：本次使用者希望管理任務頁綜觀全局，選取多案後顯示全部所選KML範圍。

## 決策

管理頁勾選任務便依既有唯一配對結果顯示範圍；兩案以上以所有已選任務的feature集合繪製，按feature.id去重。一案多地號、MultiPolygon與孔洞完整保留，沿用紅框／橘色25%填色。共用地籍只畫一次，不合併任務、工作量或任務ID。

範圍以實際選取集合為準，包含跨頁及仍保留勾選的篩選外任務；已離開管理可見來源或已刪除者依既有選取清理機制移除。勾選／取消與選取本頁會更新並縮放範圍；一般重繪只更新、不持續搶視野。新增批次「查看選取範圍」可切換手機地圖頁籤並縮放，原地圖縮放鈕有選取時亦採選取集合。

選取集合優先於點選單案；查看單案詳情不清除選取。多選總覽移除單案導航釘、取消入口設定模式並停用地圖入口編輯，避免不明確地修改某一案。縮回一筆或清除選取後恢復單案模式與入口操作；明確進入詳情的單案表單仍依原task.id操作。清除時如無有效聚焦任務則移除總覽圖層。

缺漏或無唯一配對的地號不猜測、不畫其他地號；部分缺漏與完全無範圍提供簡短地圖狀態。總覽無圖形時不拿導航點冒充範圍。現場人員／廠商仍維持原本一次一案地圖。

## 未採方案與影響

未只畫目前頁、重複堆疊共用地籍、以bbox或導航點當地籍、不依地號拆案，也不新增後端或修改派工包。只變更共用app.js的管理分支、管理HTML批次按鈕與資源版本；無新儲存欄位或寫入動作。文件任務交換、公開data及本機照片保留。

## 實際驗證與限制

新合成瀏覽器suite驗證跨頁26案／篩選選取、一案多地號、共用範圍去重、孔洞／多區塊、歧義與缺漏、fitBounds／手機、入口保護、刪除後圖層與照片保留、現場單案隔離。手動刪除、修改地號、管理底圖、完成／空發布、前月加回、文件任務匯入六組必要回歸通過，共七組。Node文件匯入測試增加PHOTOSHEET_CHROMIUM指定既有瀏覽器路徑的選項；不改產品相容性門檻。初次測試步驟與缺瀏覽器失敗如實記錄於[交接](../HANDOFF.md)及[驗證](../verification/selected-task-map-overview.json)。

未實機、WebKit、全套或大批KML效能驗收；範圍顯示以本機已匯入且可唯一配對的地籍為限。原生多頁GPS未解限制保留。這是多案地籍總覽，不是路線排序或任務指派變更。
