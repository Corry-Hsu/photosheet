# ADR-0021：案件由文件工具建立，地籍以管理備份回傳

2026-11-23，採用。使用者要求移除管理頁Excel匯入，並讓本機文件產生器使用既有XML/KML配對成果。局部取代0020與早期Excel來源規則；不更動任務識別、派工或發布契約。

管理頁保留「匯入文件任務」及手動新增；移除Excel匯入按鈕、隱藏輸入及事件處理，不再載入excel.js。ExcelJS因文件下載仍需保留，excel.js檔案及其他入口不刪，既有任務不重建。XML/KML匯入、配對面積與下載備份流程保留。

既有管理備份已含features與task.landArea逐地號面積證據，無須再建立新的備份格式。文件端從該備份另設選擇性地籍回傳，不整案替換完整文件欄位。這不是即時同步，也不能復原未配對的原XML原檔。原備份可含敏感資料，只在本機使用，不能放公開data。

未採方案：管理頁保留兩個同時建立主案件的來源；以管理備份整案覆寫文件；將私密管理備份發布到GitHub供文件端抓取。驗證以管理頁實際下載及文件端匯入合成流程、原JSON接收端與發布回歸為準，不代表手機實機驗收。
