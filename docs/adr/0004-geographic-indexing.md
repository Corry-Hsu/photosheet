# ADR-0004：KML／XML 精確鍵、背景匯入與分片

- 狀態：已採用（本次回溯整理；原始實作時間見PR）。
- 整理日：2026-11-20；核對基準：8258a42。
- 證據與範圍：[PR #1](https://github.com/Corry-Hsu/photosheet/pull/1)、[#4](https://github.com/Corry-Hsu/photosheet/pull/4)；[core.js](../../core.js)、[geo-worker.js](../../geo-worker.js)、[db.js](../../db.js)。

## 背景

地籍檔案很多，單靠段名／地號易跨段誤配，全部原始檔每次載入會拖慢現場。

## 決策／改了什麼

四碼代號＋縣市＋地號／唯一段對照配對；0582/1198可直接解析。KML統一WGS84 [lng,lat]，保留孔洞、多區塊，片段去重。使用Worker解壓／解析、RBush空間索引；IndexedDB每1000範圍一片；現場僅發布任務相關子集。

## 為什麼

處理原始檔量且保留正確範圍，支援無XML仍有KML代號的情況，符合使用者提供的代碼模式。

## 未採用／已取代的方案

不採只按地號數字／段名任取、全部地籍發到每支手機、網路連結自動讀取、把投影座標直接當經緯度，也不拿bbox或其他地號充當真實邊界。

## 影響與取捨

缺唯一索引會缺範圍，不能保證全部任務都有地籍；需提示資料錯誤與容許核對入口，但不再常駐顯示配對結果徽章。範圍導引與車輛可通行不同。
