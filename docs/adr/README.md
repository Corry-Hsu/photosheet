## 新增規則

後續從0014編號。狀態可用提議、已採用、已拒絕、已取代、局部被取代。新決策連回舊編號，舊文件只加狀態／取代連結，不改寫歷史內容。每版文件更新可以沿用未改變的ADR，不必替每個純資料刪除虛構架構決策；資料變更仍須寫交接與驗證。模板見[TEMPLATE](TEMPLATE.md)。
